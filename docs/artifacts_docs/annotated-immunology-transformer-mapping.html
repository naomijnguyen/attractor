Immunology ↔ Transformer: Analogy Map

An exploratory set of analogies for thinking — not a claim about transformer internals. Rated by whether each carries a true intuition or a misleading one.

Illuminating Illuminating · with caveat Misleading
Illuminating = imports a true intuition about how transformers work.  Caveat = the intuition is real but has a boundary worth naming, or a label to fix.  Misleading = imports an intuition that isn't true of the mechanism. Since the goal is understanding, "loose" is not a demerit — only "misleading" is.

Section 2 — Component analogies

AnalogyRatingNotes
HEVs → Residual stream Illuminating Reframed as "how context is carried through," this lands well. The residual stream is the persistent channel every layer reads from and writes back into — the conduit that threads state through depth. Better than the doc's "stabilized by upstream signals."
TLS formation → Attractor basin formation Caveat Self-flagged speculative. Fine as a metaphor for context narrowing the response space (a real conditioning effect). Just don't read it as the model literally having dynamical basins inside a forward pass.
Germinal centers → Training iterations Caveat Stronger than I first said. Both are "opaque internal process → generalization under a target," and SGD does carry real stochastic noise (mini-batch sampling, implicated in generalization). Boundary to keep: the randomness sits in different places — SHM is propose-random / select-directed; SGD is directed-propose with noise on top.
PD-1/PD-L1 → Attention masking Misleading (Parked for a later pass.) As stated it conflates a fixed, deterministic causal mask with an adaptive, signal-dependent brake — different kinds of thing.
CD28–CD80/86 → LayerNorm / residual connections Caveat Bundles two separate mechanisms (normalization vs. skip connections). Pick one — the "required co-signal" intuition fits residual connections better than LayerNorm.
CTLA-4 vs CD28 → Softmax competition Illuminating Softmax forces attention weights to sum to 1, so tokens genuinely compete for a fixed budget. A real shared property — the sharpest row.
Chemokines → Positional encodings Caveat Both are about "where," but a positional encoding is a fixed index signal, not a diffusible gradient. Useful as a pointer, thin if pushed.
TCR-MHC → Token-to-token attention Illuminating Attention is pairwise, specificity-weighted interaction between units. "Specific recognition" is a fair intuition to carry over.
BCR repertoire → Model weights Illuminating Weights are representations shaped by exposure. True, if generic to any learning system.
Cis interactions → Per-token MLP processing (relabeled) Caveat The phenomenon is real — a word with two senses gets a context-dependent representation. Only the label needs fixing: the "within-token" transform is the MLP/feed-forward sublayer, not a kind of self-attention.
Trans interactions → Cross-token attention Illuminating Context pulled in from other tokens is exactly what attention does — the reason it beat static embeddings. Pairs cleanly with the relabeled cis row: trans = context in, cis = the token's own transform.
Naive CD8 T cells → First transformer layer Caveat Early layers do capture lower-level features ("present, not yet specialized"). Just don't pin it to the literal first layer — it's a gradient across depth.
Memory T cells → Trained weights Illuminating Weights persist patterns from prior exposure. Fine.
CD160/lipid raft → Feature context-dependency Illuminating Points straight at a real, documented finding: polysemanticity / superposition — features behave differently depending on context. The "study in context, not isolation" instinct is a live interpretability debate.

Section 5 — Signaling cascade analogies

AnalogyRatingNotes
Surface receptors detect patterns → Attention detects token patterns Illuminating Attention computes token relevance. Fair high-level intuition.
Signal transduction (NF-κB) → Non-linear activations Caveat Activation functions supply non-linearity, but they aren't a multi-step signaling cascade. Don't carry over the "relay" intuition.
Cytokine production → Layer outputs added to residual stream Illuminating Layers genuinely write their outputs into the residual stream. Mechanically apt.
Cell recruitment by diffuse signals → Activating heads in later layers Caveat Later layers do read earlier outputs, but "recruitment" imports an agency the mechanism doesn't have.
HEV stabilization → Layer normalization Illuminating LayerNorm normalizes/stabilizes activations as they accumulate — consistent with the HEV-as-conduit reframe above.

Section 4 — Attractor-basin narrative

Caveat  The core intuition is real: context conditions what comes next, so a conversation does narrow the space of likely continuations. Keep the canyon / centrifugation imagery explicitly as metaphor — the architecture has no literal attractor dynamics within a forward pass.

Misleading  The AI column — HVEM → "orchestration layer," BTLA → "safety layer," DcR3 → "noise filter," CD8 T → "the transformer itself" — is assigned, not derived from any identifiable component. The receptor biology may be fine; the AI labels don't carry intuitions about real mechanisms. Of the two artifacts, the Section-2 map is the one worth developing.
